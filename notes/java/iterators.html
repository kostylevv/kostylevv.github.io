Iterable Ч базовый интерфейс коллекций; foreach использует iterator().

  • Iterator: hasNext(), next(), опциональный remove();
  • remove() может быть не поддержан Ч UnsupportedOperationException;
  • ћодификаци€ коллекции вне итератора => ConcurrentModificationException.
List list = new ArrayList<>(List.of("a","b","c"));
Iterator it = list.iterator();
while (it.hasNext()) {
    String v = it.next();
    if ("b".equals(v)) it.remove();
}
System.out.println(list); // [a, c]
