Test lifecycle annotations in JUnit5

  • JUnit5 creates new instance of the test before exec each method (@TestInstance is set PER_METHOD by def)
  • To run all tests on same instance use @TestInstance(TestInstance.Lifecycle.PER_CLASS)
  • @BeforeAll, @AfterAll are static methods if PER_METHOD is used
  • @RepeatedTest allows to set how many times test should run
  • PER_METHOD lc: @BeforeAll -> Constructor -> @BeforeEach -> test -> @AfterEach -> Constructor -> next test or @AfterAll
  • PER_CLASS lc: Constructor -> @BeforeAll -> @BeforeEach -> test -> @AfterEach -> next test or @AfterAll
